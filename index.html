Attendance Schedule

Choose which weekdays (Monday–Sunday) count as class days, by Year Level or Section. Attendance is graded on class days only.

ⓘ
How it worksA Section setting overrides the Year Level setting, which overrides the Default (Mon–Fri). Present/Absent marks on non-class days are ignored in the attendance grade. The attendance weight stays at 10% unless you change it in Grading Options.

GRADING CONFIGURATION

Edit Grade Computation

Set the highest possible score of each item (10, 20, 50, 100 or any number), turn Summative On/Off, and set the percentage weight of each component. A component score is the total score ÷ highest possible total, and the weights of the components that are On must total exactly 100%.

✓
Automatic computationChanging a weight immediately changes the final grade calculation and Excel reports. Attendance remains automatically calculated from attendance records.
