# BCC Student Grading & Attendance Management System v22

Premium UI/UX refinement based on the supplied Grades and sidebar design direction.

New in v22 - multi-item grading:
- Quiz 1-4 (total / 4), Activity 1-4 (total / 4), Summative 1-2 (total / 2), Midterm + Final Exam (total / 2), Performance Task (score)
- Component weights add up to 100 (default 15 / 15 / 10 / 30 / 20 plus 10 attendance) and can be changed by each teacher under Settings > Grading Options > Edit
- Template download, bulk import and Excel reports use one column per item

Editable scoring (v23):
- Each Quiz, Activity, Summative, Midterm, Final Exam and Performance Task item has its own highest possible score (10, 20, 50, 100 or any number)
- Component score = total score / highest possible total x 100; Summative can be switched On/Off; weights of the On components must total 100
- Settings > Grading Options > Edit (includes Quick set, Auto-balance and Reset)

Attendance schedule (v22):
- Class days per week (Monday-Sunday) can be set as a Default, per Year Level, and per Section (Section overrides Year Level). Settings > Attendance Schedule > Edit
- Attendance grade counts Present/Absent only on a student's class days; attendance weight stays 10% unless edited in Grading Options
